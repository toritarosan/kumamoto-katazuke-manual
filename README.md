## このページの設計思想

支援情報ダッシュボード（姉妹版）が「いま何があるか」の一覧なのに対し、本ページは**手順書**。
「写真→罹災証明→事前相談→片づけ→分別搬入」の**順番を間違えると受けられる支援が減る**、という一点を伝えるために作っている。

- STEP 0 安全確認（応急危険度判定と罹災証明の混同を解く表を含む）
- STEP 1 片づけ前の写真（全支援制度の入口）
- STEP 2 罹災証明（両市の窓口実情）
- STEP 3 修理・保険・解体（「先払いすると制度が使えない」を強調。公費解体は両市とも受付未発表=勝手に解体しない）
- STEP 4 片づけ作業（熱中症・破傷風・石綿・**断水下の片づけ**・宅内漏水チェック・ボラセン依頼）
- STEP 5 災害ごみ（両市の仮置場詳細）
- してはいけないこと10か条／悪質商法（点検商法）／相談先電話一覧／未確認事項／リンク集

## 編集方針（姉妹リポジトリと共通の規律）

1. **出典主義**: 全カードに出典リンク＋更新日/確認日。出典を示せない事実は書かない
2. **未確認の明示**: 「まだ確認できていないこと」セクションで未発表事項を明示。ねつ造は絶対にしない
3. **一次情報優先**: 市公式 > 県・国公式 > 全国機関 > 報道
4. **URLを推測しない**: 八代市のkiji番号は[関連情報ページ](https://www.city.yatsushiro.lg.jp/kiji00326750/index.html)のリンク一覧で実物を照合（8/9照合済み。旧り災証明ページkiji00324826・旧ボラセンページkiji00326762は404化→現行URLに差し替え済み）
5. **別災害の混入に注意**: 八代市社協の「R07」系ページ・宇城市社協の2025年豪雨ページは**別災害**。ボラセン情報は市の現行ページ（kiji00326822）と社協の今回災害ページ（oshirase/12239）のみを出典にする
