## 編集方針（姉妹リポジトリと共通の規律）

1. **出典主義**: 全カードに出典リンク＋更新日/確認日。出典を示せない事実は書かない
2. **未確認の明示**: 「まだ確認できていないこと」セクションで未発表事項を明示。ねつ造は絶対にしない
3. **一次情報優先**: 市公式 > 県・国公式 > 全国機関 > 報道
4. **URLを推測しない**: 八代市のkiji番号は[関連情報ページ](https://www.city.yatsushiro.lg.jp/kiji00326750/index.html)のリンク一覧で実物を照合（8/9照合済み。旧り災証明ページkiji00324826・旧ボラセンページkiji00326762は404化→現行URLに差し替え済み）
